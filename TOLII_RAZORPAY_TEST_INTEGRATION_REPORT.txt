2. INTEGRATION ARCHITECTURE
--------------------------------------------------------------------------------
A. Authoritative Server-Side Flow:
   1. Slot Selection & Hold:
      - Flutter client requests interval hold via POST /api/bookings/prepare-payment.
      - Server validates operating hours, closing time, and existing overlaps.
      - Server calculates authoritative price in integer paise (rate * duration / 60).
      - Server places 10-minute hold (HELD) in memory and Firestore.
      - Server creates genuine Razorpay order using server TEST MODE credentials.
      - Server returns keyId, razorpayOrderId, amountPaise, and bookingId.

   2. Native Client Checkout:
      - Flutter client launches Razorpay SDK modal with server-provided public keyId
        and razorpayOrderId.
      - Client secret is NEVER sent to or stored in Flutter code.
      - On payment completion, Razorpay returns paymentId, orderId, and signature.

   3. Server-Side HMAC Verification:
      - Flutter sends tokens to POST /api/payments/verify.
      - Server recalculates HMAC-SHA256(orderId + '|' + paymentId, RAZORPAY_KEY_SECRET).
      - Server verifies signature using timing-safe comparison (crypto.timingSafeEqual).
      - Server matches orderId against the booking record and verifies status.
      - Server transitions booking to CONFIRMED and payment to CAPTURED.

   4. Webhook Reconciliation:
      - Razorpay sends event to POST /api/webhooks/razorpay.
      - Server verifies X-Razorpay-Signature against raw body and RAZORPAY_WEBHOOK_SECRET.
      - Deduplication engine checks event ID to prevent duplicate side-effects.
      - Updates booking state to CONFIRMED (payment.captured) or CANCELLED (payment.failed).

6. MANUAL STEPS TO COMPLETE ON RAZORPAY AND RENDER
--------------------------------------------------------------------------------
Step 1: Configure Environment Variables in Render Dashboard
   1. Log in to your Render Dashboard (https://dashboard.render.com).
   2. Navigate to your 'tolli-app' web service.
   3. Click 'Environment' in the left sidebar.
   4. Add the following environment variables (using values from your rzp-key.csv):
      - RAZORPAY_KEY_ID = <your rzp_test_ Key ID from rzp-key.csv>
      - RAZORPAY_KEY_SECRET = <your Key Secret from rzp-key.csv>
      - RAZORPAY_WEBHOOK_SECRET = <a secure random secret string of your choice>
   5. Save Changes. Render will automatically redeploy the service.

Step 2: Configure Razorpay Webhook in Razorpay Dashboard
   1. Log in to your Razorpay Dashboard (https://dashboard.razorpay.com).
   2. Ensure the top toggle is set to 'Test Mode'.
   3. Navigate to Settings -> Webhooks.
   4. Click 'Add New Webhook'.
   5. In the Webhook URL field, enter:
      https://tolli-app.onrender.com/api/webhooks/razorpay
   6. In the Secret field, enter the exact RAZORPAY_WEBHOOK_SECRET value you added
      to Render in Step 1.
   7. Under 'Active Events', select:
      - payment.captured
      - payment.failed
      - order.paid
   8. Click 'Save Webhook'.

Step 3: Deploy Updated Backend Code to Render
   - Push the updated backend code (server/index.js, server/package.json) to your
     connected Git repository branch that Render tracks (e.g. main/master).

Step 4: End-to-End Verification on Android Device
   1. Run the app on your Android device (or via ADB reverse proxy for local testing):
      If testing with local backend:
      run: adb reverse tcp:3000 tcp:3000
      If testing with deployed backend:
      The app automatically targets https://tolli-app.onrender.com.
   2. In the TOLII app, select Venues -> Sports Arena Sidsar -> Court 1.
   3. Choose Date, Duration (e.g. 60m), and an available time slot.
   4. Tap 'Continue' to open Booking Review.
   5. Tap 'Pay via Razorpay'.
   6. In the native Razorpay test modal, select 'Card' (or 'Netbanking' / 'UPI').
   7. For card, use Razorpay test card credentials (any valid future expiry and CVV).
   8. Complete payment with the Razorpay Test OTP (select 'Success').
   9. Verify that BookingStatusScreen displays 'Booking Confirmed' and the booking
      appears under 'My Bookings'.
